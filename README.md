# 上海倖存者 / Shanghai Survivors

以上海病毒爆發為背景的城市生存遊戲原型。斜俯視第三人稱、單機、低多邊形風格；畫面呈現參考《保衛台北》。

> 遊戲以**真實上海街區**為場景；目前已結合 CMAB 建築資料及 OpenStreetMap 道路，製作首個可行走的街區白模。
> 第三方資料與素材依各自條款記錄來源及使用方式。詳見 [docs/asset-license.md](docs/asset-license.md)。

## 病毒爆發首版（本地候選）

沿用真實上海街區與角色／戰鬥，參考《保衛台北》的「城市搜刮—資源壓力—避敵—接應」循環，以病毒爆發下的多方衝突取代台北原劇情；保留軍方、警察與其他倖存者威脅。

- `web/survival.html`：一局 8 分鐘。搜刮至少 3 處，最後 60 秒回出生點綠圈（5m 內），暴露壓力低於 85，按 **E** 撤離；超時失敗，不再到點自動獲勝。
- 水分／飽足隨時間消耗；奔跑消耗較快。水與罐頭同時補充需求；耗盡後持續掉血。
- 感染者在 4m 內且無牆遮擋會增加暴露壓力，拉開距離會下降。醫療包降低該值。**這是虛構風險機制，不是感染率、診斷或治療模型。**
- **C** 切換潛行，降低移速與被察覺範圍；**Esc** 暫停／繼續。社區廣播按進度交代危機與接應窗口。
- 敵人分為感染者、軍方封鎖隊（12m 遠程、1.5 秒預警）、警方警戒隊（近戰壓制體力）、掠奪者（快追、搶水），各有配色；人類敵人加帽型剪影，軍方加槍形。尚非完整小隊戰術／彈道系統。綠圈黃色互助者按 **E** 用一罐罐頭換一瓶水。
- 保留原戰鬥、12 位角色與上海資料；尚未等同《保衛台北》的完整多日沙盒。存檔、NPC、載具、完整室內與手機手感仍待實機驗證。
- 本地測試：`node web/tools/test-outbreak.mjs`；建置：`cd web && npm run build`。不使用 CI；本地測試結果與發布界線見 `docs/survivors-first-pass.md`。

下方歷史進度記錄包含舊原型設定；現行首版以上述與程式碼為準。

## 操作對齊保衛台北

桌面：WASD 移動、Shift 奔跑、C 潛行、滑鼠瞄準／按住左鍵攻擊、Q 推開、E 互動／按住搜刮、F 手電筒、Tab/I 背包（點物品使用／裝備）、Esc 先關背包否則暫停。舊 1–4 使用物品及 G 開槍已取消，避免與台北時間倍率／掩體鍵衝突。保留 J/K 為舊近戰／投磚輔助鍵。

手機：搖桿移動，外圈奔跑；情境鍵依距離顯示打／搜／換／撤，蹲鍵切換潛行；頂部背包與暫停。Space 上海仍是跳躍，尚非台北翻越；未實作的地圖、避難所、封門、睡眠、倍率、狙擊鏡不顯示假功能。手機長按情境鍵轉攻擊與長按蹲自動撤退尚未對齊。瀏覽器實機操作仍待驗證。

初始樣本見 [shanghai_huangpu_250m.json](data/samples/shanghai_huangpu_250m.json)：以 250 × 250 m 視窗選取相交建築，完整保留跨視窗的原始多邊形，故部分建築會超出範圍。來源 SHP 座標系為 EPSG:3857，已轉換為 UTM 51N（EPSG:32651）的局部公尺座標。來源與校驗資訊見 [CMAB 來源](data/sources/cmab-v7/SOURCE.md)。

原始樣本保留高度欄位原值，單位對應尚未獲作者明確證實；白模暫按米解讀，詳見[樓高核對](docs/cmab-height.md)。樣本是推算的屋頂輪廓，與現地地面範圍是否一致尚未驗證。[OSM 道路](data/sources/osm-shanghai-20261029/SOURCE.md)使用同一座標系，路寬是估計值，部分路線與建築輪廓重疊，原因未確認。

目前本機已安裝依賴，可雙擊 [web/start.cmd](web/start.cmd) 啟動網頁原型，或在 `web/` 執行 `npm install` 和 `npm run dev`。WASD 按螢幕方向移動，滑鼠滾輪縮放；一棟建築有測試用示意門洞和空白室內，並非真實門位。街區另有程序生成的店面、招牌、陽台及路邊物件，並非實景紀錄。操作及資料限制見 [web/README.md](web/README.md)。早期 Godot 原型已自工作區移除（連同 241.9 MB 的引擎與快取），需要對照時可從 commit `cd32f57` 取回。喪屍與生存循環在 `web/survival.html`，`web/index.html` 仍是純街區瀏覽原型。

## 里程碑：7 天垂直切片

判準只有一個：**陌生人玩 10 分鐘後，會不會想再玩一次。**
不會 → 調玩法，不要加城市。

| 天 | 目標 | 完成判準 |
|---|---|---|
| 1 | 專案可跑 | 俯視第三人稱能走、能跳、有手電筒 |
| 2 | 一個街區 | 以選定的上海街區建築資料做白模，能進出其中 1 棟 |
| 3 | 一隻喪屍 | 會朝你走、會撞牆繞路、近戰 3 下能打死 |
| 4 | 生存壓力 | 體力、手電筒電量、噪音會吸引喪屍 |
| 5 | 一局遊戲 | 撐過一夜 = 勝利；死亡 = 結算畫面 |
| 6 | 手感 | 打擊反饋（頓幀、音效、血）、視角晃動、腳步聲 |
| 7 | 存檔 | 能存能讀，關掉再開還在 |
