# CMAB 上海樣本的樓高欄位

核對日期：2026-10-29。

CMAB 作者的[論文](https://doi.org/10.1038/s41597-025-04730-5)描述以模型預測建築高度，單位為米，結果不是逐棟實測。隨資料提供的 `data/sources/cmab-v7/metadata.csv` 將 `pred_h_r` 描述為建築高度（m）。

實際取得的上海 processed Shapefile 使用 `Height` 欄位，而非 `pred_h_r`；目前未找到發布方對兩者逐欄映射和缺失值代碼的明確說明。因此白模若把 `Height` 當米使用，是有論文背景支持的**暫行假設**，不是已證實的欄位映射。保留原值供核對；無效值使用明確標註的佔位高度，不稱為實測。

目前 250 m 樣本的 61 筆來源記錄 `Height` 都是正數，約 10.15 至 38.71，中位數約 19.78。這些統計只描述樣本欄位的數值，並不驗證實際樓高。屋頂輪廓、預測高度與各道路資料的日期和精度可能不同。
