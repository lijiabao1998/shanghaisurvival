# 上海倖存者：安全屋與持久生存候選

基線：`14d0e825`。本批不重抓地圖、不複製台北程式、不使用瀏覽器自動驗收或測試 CI。

## 真正新增的循環

- 開場選擇「生存沙盒」或獨立「8分鐘快速撤離」。快速模式不覆寫沙盒存檔。
- 預設街區既有 CMAB 建築 `cmab_327822_0` 為安全屋；藍色門標距出生約4.2m。門內外位置與0.36m玩家碰撞半徑已做非瀏覽器幾何檢查。
- 靠近門按 E／手機「家」進入，敵人在6m內且有視線時不能進入。進入後展示原建築內部的簡化床／物資箱，隱藏該屋頂；此版室內用管理面板，不是自由走動或建造系統。
- 每次存／取一件物資；休息花庫存一水一罐頭、推進120模擬秒、回25HP和體力、補充部分需求。手槍隨角色攜帶，不能存倉。
- 每3秒與物資交易、入出屋、離頁、死亡保存一個完整快照；物資、已搜地點、敵人死亡、角色、位置、時間一起保存，不分開寫入造成讀檔重複搜刮。
- 再開同來源／同路徑／同瀏覽器選「繼續」；未知版本、損毀、不同地圖資料格式拒絕載入。死亡記錄不能復活；開始新沙盒重置全局，庫存不跨死亡保留。不是雲端同步，清瀏覽器資料會丟失。
- 12真實分鐘一遊戲日，08:00開始；光照/天空隨日夜變化，夜間感染者感知提高35%。已搜物資不刷新，沒有假裝無限補給或完整NPC記憶。

## 擁有者實玩指南（全部等待擁有者實玩）

入口 `survival.html`（正式站如以此頁為index則直接網站入口）。選角色→生存沙盒→藍門按E進屋→各存1水1罐頭→休息→返回街區→搜刮→帶回物資→關頁重開按繼續。

- 電腦：WASD移動、Shift跑、C潛行、滑鼠瞄準／左鍵攻擊、Q推開、E互動／按住搜刮、F手電筒、Tab/I背包、Esc關背包／出安全屋／暫停。滾輪縮放。
- 手機：左搖桿外圈跑、右情境鍵打／搜／換／家、蹲、背包；安全屋內直接點存取／休息／返回。測直向和橫向遮擋、多指操作、切背景返回。
- 優先核對：門標與可讀室內、按鍵不黏、搜刮後重新載入不再出現補給、存取總量不變、休息確實扣庫存、死亡不能讀回上一活人、快速挑戰仍有最後一分鐘撤離且不破壞沙盒。
- 最終畫面、人物街道比例、手感、敵人平衡、效能皆未由工具實玩確認。
