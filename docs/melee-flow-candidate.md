# 持械動作連接候選（未部署）

基於 main `27ed3fc`，包含現有雙持／傷勢／背包及上海室內外細節；不改存檔格式、角色 ID 或武器掛點。

- 同手在 0.32 秒內續擊會正手／反手交替；左右手各使用相同手別的姿態與判傷弧。原有 6 點體力與單次目標傷害保持不變。
- 收招（動作進度 62% 後）可緩衝一次明確按鍵／點擊；早按不排隊，不堆積無限連擊。長按仍逐次自動攻擊，釋放不額外排隊。
- 蓄勢及收招與當前步態混合，避免手臂和雙腿突然被拉回固定站姿。
- 實際命中才有 35ms 攻擊動畫停頓、敵人短暫後仰、清除敵方蓄勢；空揮不製造命中頓感。角色移動及世界時間不凍結。
- 背包、暫停、失焦／取消清空緩衝，低體力不免費補下一擊。保留牆體遮擋與一揮一目標只受一次傷。

`?debug` 的 `combatFixture()` 僅為隔離瀏覽器測試擺放近距離敵人；測試使用真實鍵盤／觸控出手，並比較目標 HP。測試會使用隔離的候選本機儲存，不能拿正式存檔當測試資料。

驗證：`cd web && npm run build`；所有 `tools/test-*.mjs`。新增正反手世界矩陣武器軌跡、步態過渡、單格輸入緩衝與低體力測試。動態證據由獨立測試分支 workflow 生成，連續截圖具有實際時間戳；若轉為影片僅為連續圖回看，不宣稱原生 60fps 錄影。自測不等於使用者手感驗收。
