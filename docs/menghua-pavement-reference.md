## 實作界線

- 改為低彩度灰連續沿街面，稀疏低對比橫接縫/修補；低淺灰路緣以細橫縫分段，配暗細排水邊。不再交替米黃大板與交叉格線。
- 地面微粒以world-space shader程序噪點繪製，不下載照片當遊戲貼圖，不需canvas。灰階值為美術近似，非校色後實測RGB。
- 所有寬度、接縫距離、路緣高度、程序粒徑均為既有遊戲尺度/保守建模參數，**照片沒有尺規，不能聲稱為實測尺寸**。
- 原OSM道路中心線、寬度估計、建築與門洞、collision及存檔完全不改；窄service/living_street/footway等保持不新增寬人行道。
- 保留原樹與燈細節；街景依然3個合批mesh。本圖只能支持鋪面視覺，不能證明每棵樹/燈/路緣的精確位置。
- 原圖是舊改前後歷史記錄，本候選為有來源的視覺詮釋，不宣稱整區測繪重建。
