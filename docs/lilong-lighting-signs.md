# 弄堂燈光與招牌（grok/lilong-realism）

參考：Wikimedia Commons 上的石庫門弄堂、上賢坊、景星路、田子坊與夜間弄堂照片（CC BY-SA，僅作研究參考，未放進 repo）。

## 對照照片後的差距
- 夜裡整片弄堂幾乎全黑：窗戶不亮、店面不亮，只有少數路燈。
- 沒有弄口的燈泡、牆上的支架路燈和地上的光池。
- 招牌只有白天看得到，晚上不發光；沒有直立式燈箱（竪招牌）。
- 石庫門門口太空：缺盆栽。

## 這次做了
- **夜間發光層**（每排房子併入一個加法混合網格，跟著房子一起淡出）：
  - 約四成窗戶亮燈：暖黃白熾燈、橘色、少量日光燈冷白。
  - 開著的店面透出室內光，地上有一圈暖光；招牌上方一條燈管。
  - 石庫門門楣下的燈泡和光池；部分房子牆上有支架路燈：弄堂裡是鈉燈橘色，街面上是較白的 LED。
  - 弄口石門樓下吊一顆裸燈泡，照亮弄口。
- **招牌**：店招、門牌、路牌在夜裡微微發光（emissive）。新增直立燈箱，用虛構店名（如「阿德面馆」「荣记生煎」「和平旅社」），不是真實商號或品牌。
- **細節**：石庫門旁的盆栽。
- **光線**：夜間霧更近一點，晨昏陽光更偏暖橘；正午色溫與夜間可讀亮度不變（測試保留）。
